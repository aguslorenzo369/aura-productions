# Ayuno — Vaciar el cuerpo, expandir la conciencia

Deck de 12 láminas. `ayuno.pptx` y `ayuno.pdf` se generan con `build.js`.

## Regenerar

```bash
npm install pptxgenjs
node build.js          # → ayuno.pptx
```

## Sistema de diseño

| Token | Valor | Uso |
|-------|-------|-----|
| Negro cálido | `#0B0A09` | Fondo |
| Panel | `#13110F` | Tarjetas |
| Hueso | `#EDE6DA` | Títulos y texto principal |
| Cuerpo | `#9E958A` | Párrafos |
| Ámbar | `#C8A45D` | Acento (una palabra por lámina) |

- **Tipografías:** Cambria (títulos y citas) + Calibri (cuerpo). Ambas vienen con
  Office, así que el archivo se ve igual en cualquier máquina.
- **Motivo:** el círculo. Lleno en la portada, vaciándose en las etapas
  fisiológicas, como halo en las láminas de pausa.
- **Ritmo:** una idea por lámina y márgenes de 1.1" — el aire es parte del mensaje.

## Nota de contenido

La lámina 10 (*Cuándo no ayunar*) no estaba en el original. Se agregó porque el
deck recomienda ayunos de más de 72 h ante una audiencia. Sacala si el marco de
la charla ya cubre las contraindicaciones.
